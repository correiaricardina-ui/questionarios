Como usar este diário.

Não é para preencher todos os dias — é para preencher quando acontecer algo que vos pareça importante registar. Episódios difíceis, mas também momentos onde algo correu inesperadamente bem.

Quanto mais próximo do acontecimento melhor — mas se passarem 2 ou 3 dias, registem na mesma. O importante é não perder.

Tudo o que escreverem fica guardado neste browser. No fim do período, fazem download ou imprimem para enviar.
