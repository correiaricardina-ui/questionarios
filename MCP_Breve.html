Painel Clínico — MCP Breve

ℹ Versão breve. Esta versão cobre apenas a estrutura básica (coabitantes, quotidiano, autoridade, posição). Para casos onde o eixo intergeracional é central na formulação, use a versão completa que inclui também relação afetiva por figura, resposta dos outros à ansiedade e síntese aberta.
⚠ Instrumento ad-hoc. O MCP é um instrumento clínico operacional, sem validação psicométrica formal. Os resultados devem ser usados como orientação clínica, sempre articulados com entrevista.
